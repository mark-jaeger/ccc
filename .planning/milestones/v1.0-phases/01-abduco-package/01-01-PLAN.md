  <name>Task 2: Add ParseSessionList parser with regex</name>
  <files>abduco/sessions.go</files>
  <behavior>
    - Parse "* Thu 2015-03-12 12:05:20\t12345\tccc.rt1.main" as attached session
    - Parse "+ Thu 2015-03-12 12:04:50\t12346\tccc.rt1.2" as dead session
    - Parse "  Thu 2015-03-12 12:03:30\t12347\tother-session" as detached external session
    - Skip header line "Active sessions (on host localhost)"
    - Empty output returns nil slice
  </behavior>
  <action>
Add to `abduco/sessions.go`:

1. Package-level regex:
```go
var sessionLineRe = regexp.MustCompile(`^([*+ ])\s+\S+\s+\d{4}-\d{2}-\d{2}\s+\d{2}:\d{2}:\d{2}\t(\d+)\t(.+)$`)
```

2. ParseSessionList(output string) []Session:
   - Trim and split by newline
   - For each line, match against sessionLineRe
   - Extract status (group 1), PID (group 2), name (group 3)
   - Call parseSessionName helper to populate Project/Suffix/External
   - Set Dead = (status == "+")
   - Return slice of sessions

3. parseSessionName(name string) Session helper (unexported):
   - If not strings.HasPrefix(name, "ccc.") → return Session{Name: name, External: true}
   - Split name[4:] by "." with SplitN(_, ".", 2)
   - If not 2 parts → return Session{Name: name, External: true}
   - Return Session{Name: name, Project: parts[0], Suffix: parts[1]}

Key: Use tab delimiters for parsing, not column positions (handles locale variation in timestamp).
  </action>
  <verify>
    <automated>go build ./abduco/</automated>
  </verify>
  <done>ParseSessionList correctly parses attached, dead, detached, and external sessions</done>
</task>

1. FilterSessionsForProject(sessions []Session, projectKey string) []Session:
   - Build result slice
   - Include sessions where s.Project == projectKey
   - Also include sessions where s.External == true (for visibility per SESS-05)
   - Return result

2. NextAutoName(projectKey string, existing []Session) string:
   - Per user decision: first session gets suffix "main", subsequent get 2, 3, 4...
   - If len(existing) == 0, return "ccc." + projectKey + ".main"
   - Check if "main" suffix already exists in existing
   - If not, return "ccc." + projectKey + ".main"
   - Otherwise, find max numeric suffix and return "ccc." + projectKey + "." + (max+1)
   - Non-numeric suffixes (like "main") are ignored when finding max

Note: Naming pattern is "ccc.{project}.{suffix}" per CONTEXT.md decision.
