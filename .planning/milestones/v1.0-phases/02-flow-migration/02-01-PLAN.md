<!-- Key types and contracts from abduco package (Phase 1) -->

From abduco/sessions.go:
```go
// Session represents an abduco session with parsed metadata.
type Session struct {
    Name     string // full session name, e.g., "ccc.rt1.main"
    Project  string // extracted project key, empty if External
    Suffix   string // extracted suffix, empty if External
    External bool   // true if not prefixed with "ccc."
    Dead     bool   // true if status is "+"
    PID      int    // process ID for kill command
}

func BuildCreateCommand(name, path string) string
func BuildAttachCommand(name string) string
func BuildListCommand() string
func BuildKillCommand(pid int) string
func BuildCheckCommand() string
func ParseSessionList(output string) []Session
func FilterSessionsForProject(sessions []Session, projectKey string) []Session
func NextAutoName(projectKey string, existing []Session) string
```

Key differences from tmux.Session:
- External (bool) replaces Verified (inverted: External=true means unverified)
- Dead (bool) new field for dead sessions
- PID (int) for kill command (tmux used name-based kill)
- No Windows field (abduco is single-window)
- No Path field (not stored in abduco session metadata)

Key differences from tmux.BuildCreateCommand:
- abduco.BuildCreateCommand takes 2 args (name, path) not 3 (tmux took name, path, project)

Example conversions:
```go
// Old: runner.responses["tmux list-sessions"] = "myapp|||myapp|||/home/user/myapp|||2"
// New:
runner.responses["abduco 2>&1"] = "  2024-01-01 12:00:00\t12345\tccc.myapp.main"
```

For multiple sessions:
```go
// Old: "myapp|||myapp|||/home/user/myapp|||2\nmyapp-2|||myapp|||/home/user/myapp|||1"
// New:
runner.responses["abduco 2>&1"] = "  2024-01-01 12:00:00\t12345\tccc.myapp.main\n  2024-01-01 12:01:00\t12346\tccc.myapp.2"
```

For external/unverified sessions:
```go
// Old (unverified by empty project): "myapp||||||/tmp|||1"
// New (external by missing ccc. prefix): "  2024-01-01 12:00:00\t12347\tmyapp"
```
